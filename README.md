## 🚀 Featured Project

### 📹 Secure AI Camera

**An AI-powered camera monitoring application combining computer vision, backend APIs, and LLM integration.**

🔗 **Repository:** [secure-ai-camera](https://github.com/nareshpogula/secure-ai-camera)

**Key features:**
- 🎯 Person detection using YOLO.
- ⚡ Python FastAPI backend.
- ⚛️ React-based frontend.
- 🧠 LLM integration for natural-language interaction.
- 🛡️ Prompt injection protection using an LLM guard.
- 📋 Detection event logging and bounded contextual queries.
- 🔒 Security-conscious handling of camera credentials and sensitive configuration.

**Technologies:** Python · FastAPI · React · YOLO · LLMs · AI Security
